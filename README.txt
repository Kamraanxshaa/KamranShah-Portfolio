ZEENIA ZAHRA — INTERACTIVE RESEARCH PORTFOLIO

Built as a responsive static website using Tailwind CSS, Alpine.js, GSAP + ScrollTrigger, and Lucide icons (loaded from CDNs).

Interactions:
- Responsive mobile navigation
- Light/dark theme toggle
- Scroll progress indicator
- Animated section reveals
- Expandable experience entries
- Research category filters
- Clickable research detail modals
- Copy-email action
- Smooth anchor navigation

Preview: open index.html in a browser with an internet connection (libraries and fonts load from CDNs).

To publish: deploy this folder to Netlify, Vercel, or GitHub Pages. Add the final public URL to the CV after deployment.
