# Kamran Shah — Personal Portfolio

A responsive React + Vite + TypeScript portfolio for a product designer working with startups and MVPs.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

The contact form currently uses a `mailto:` fallback and does not store submissions. Replace `hello@kamranshah.work` in `src/App.tsx` with the preferred contact email, and connect a form backend if server-side submissions are required.

Project visuals are CSS-generated interface mockups. Replace them with approved screenshots and case-study assets as they become available. Review all profile metrics and project descriptions before publishing.
